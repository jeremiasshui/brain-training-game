# 🌿 療癒系左右腦訓練遊戲

一個專為老年人設計的友善腦力訓練網頁小工具。

## ✨ 特色

- 🎨 **療癒配色**：清新自然的綠色、藍色、淺黃色系
- 💬 **正向鼓勵**：豐富的鼓勵語句，增加遊戲樂趣
- 📊 **進度追蹤**：記錄分數、連勝次數、完成遊戲數
- 👴 **長者友善**：大字體、大按鈕、清晰指示

## 🎮 遊戲內容

1. **🎴 記憶卡片** - 訓練視覺記憶（右腦）
2. **🔢 數字記憶** - 訓練邏輯記憶（左腦）
3. **🎨 顏色配對** - 訓練色彩辨識（右腦）
4. **➕ 快速計算** - 訓練數學運算（左腦）

## 🚀 使用方式

直接打開 `index.html` 即可開始遊戲！
